# Zepto-SQL---Project
This project presents a comprehensive SQL-based analysis of Zepto’s product dataset containing 3,732 records across 14 categories. The objective is to demonstrate strong SQL fundamentals including database design, data cleaning, transformation, and analytical querying to generate meaningful business insights.

The project begins with the creation of a dedicated database and a structured product table. Data quality checks are performed to identify null values, duplicate products, invalid pricing, and stock inconsistencies. Records with zero MRP are removed, and price values are standardized by converting them from paise to rupees for accurate reporting.

Using SQL queries, the analysis explores discount effectiveness, identifies high-value promotional products, examines premium products with low discounts, and validates discount logic. Additional insights include category-wise product distribution, stock availability analysis, price segmentation into low, medium, and high ranges, and total inventory weight by category to support logistics and warehouse planning.

This project is suitable for academic submission and showcases practical SQL skills relevant to data analyst roles, including data validation, business-oriented analysis, and structured query writing.
